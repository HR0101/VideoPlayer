# VideoPlayer (iOS Prototype)

アルバム管理、サムネイル生成、AVPlayer 再生制御を備えた iOS 向けビデオプレイヤーの初期プロトタイプ実装です。

---

## ✨ 主な機能

- **アルバム・フォルダ管理 (`AlbumListView`)**
- **グリッドサムネイル表示 (`VideoGridView`)**
- **カスタム動画再生コントロール (`PlayerViews`)**
- **ファイルアプリ連携 (`DocumentPicker`)**

---

## 🛠 技術構成

- **プラットフォーム**: iOS 16.0+
- **言語**: Swift
- **UIフレームワーク**: SwiftUI
- **メディア**: AVFoundation, AVKit
